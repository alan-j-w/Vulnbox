Acceptable Use Policy (AUP)

Last Updated: March 2026

1. Permitted Uses

The VulnBox platform is an educational environment engineered to simulate real-world vulnerabilities. You are explicitly authorized to use hacking and penetration testing techniques against the provided challenge targets (designated lab endpoints).

2. Prohibited Uses

You may NOT under any circumstances:

  • Attack the platform's core infrastructure, including the database, authentication systems (unless part of a specific lab module), or the host operating system.
  • Launch Denial of Service (DoS) or Distributed Denial of Service (DDoS) attacks against any VulnBox server or infrastructure.
  • Attempt to pivot from the VulnBox lab environment to attack other users, internal network structures, or external targets.
  • Utilize the platform to host, distribute, or execute malicious software, payloads, or botnets outside the strict confines of a lab challenge.
  • Use automated vulnerability scanners (e.g., Nessus, OpenVAS, Acunetix) on the platform, as it generates excessive noise and disrupts the environment for others. Manual testing and script creation (e.g., Python scripts for brute-forcing in designated labs) are permitted.

3. Reporting Vulnerabilities

If you discover a vulnerability in the core VulnBox infrastructure (not the intentionally vulnerable labs), you must report it immediately to our security team. Do not exploit it further.
